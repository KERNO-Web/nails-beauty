# «На пять»: сайт студии маникюра (шаблон)

Демо-студия вымышлена. Сайт продаётся салонам как шаблон: для нового салона меняется `src/data.ts` (название, адрес, услуги, мастера, работы, отзывы) и фото.

- Первый экран: пять работ в окнах-«ногтях» веером, как раскрытая рука.
- Цены по разделам, лента работ с фильтром и окном «Хочу так же», мастера с днями работы.
- Онлайн-запись: свободное время считается в `src/slots.ts` по графикам мастеров. В демо записи хранятся в браузере (localStorage), часть окон занята для примера. Для живого салона нужен сервер.
- Шрифты Unbounded и Golos Text, акцент — кобальт.

```bash
npm install
npm run dev   # http://localhost:5193
npm run build
```
