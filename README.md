# Студия маникюра — шаблон с онлайн-записью

Мобильный сайт для nail-мастера или небольшой студии: услуги и цены, работы, мастера,
онлайн-запись по реально свободным окнам, контакты. Плюс кабинет мастера (`/#/admin`).

```bash
npm install
npm run dev      # http://localhost:5190, кабинет — http://localhost:5190/#/admin
npm run build
```

## Как сделать сайт под нового клиента

1. `src/data/demo.ts` — название, адрес, контакты, цвет акцента, мастера с графиком, услуги, работы, отзывы.
   То же самое можно поменять мышкой в кабинете → «Студия», «Услуги», «Работы», «Отзывы», «График».
2. Фото: id снимка Unsplash (`photo-…`) или обычная ссылка/путь (`/photos/hero.jpg` из `public/`).
3. Один мастер — выбор мастера и блок «Мастера» на сайте исчезают сами. Два и больше — появляются.
4. Для настоящей студии выключить «Демо: заполнять расписание выдуманными записями» (кабинет → Студия).

Цвет: один `accent` в данных — от него считаются выделения, выбранное время, курсивы в заголовках.

## Устройство

- `src/lib/slots.ts` — движок свободного времени (логика из shina-booking/shared/slots.ts:
  «пост» стал мастером со своим графиком, выходными и списком услуг; «любой мастер» = кто свободен).
- `src/lib/store.ts` — данные и записи. Сейчас хранятся в браузере (localStorage) — для демо.
  Запись перепроверяет окно перед сохранением, как это делает сервер.
- `src/lib/contact.ts` — телефон (проверка из shina-booking/shared/phone.ts) или ник в Telegram.
- `src/sections/` — блоки страницы: `Top` (шапка, первый экран), `Showcase` (услуги, работы, мастера, шаги),
  `Booking` (запись), `Bottom` (преимущества, отзывы, контакты, подвал).
- `src/admin/` — кабинет: записи по дням и мастерам, ручная запись, отмена, график и отпуска, услуги, работы, отзывы, настройки.
- `src/styles.css` — токены (цвета, радиусы, шрифты) в `:root`, дальше компоненты. Шрифты локальные:
  Tenor Sans (логотип, заголовки, цены — без курсива) и Onest (интерфейс), оба с кириллицей.

## Что нужно до боевого запуска

- Сервер: записи сейчас живут в браузере, мастер не увидит записи клиента с другого устройства.
  Нужно подключить `store.ts` к API (подойдёт сервер shina-booking: Hono + PostgreSQL, логика слотов та же)
  и закрыть кабинет паролем.
- Уведомления мастеру о новой записи (Telegram-бот) и напоминания клиенту — со стороны сервера.
- Фото: демо берёт снимки с Unsplash по ссылке. Для клиента — его собственные фото в `public/`
  (внешние CDN из РФ могут открываться медленно).
- Отзывы в демо — примеры текста. Публиковать только настоящие.
