# Демо для салонов маникюра — zapisvonline.ru/<slug>

Продаём салону сайт с онлайн-записью под его название: **4 000 ₽ один раз, без абонплаты**.
Демо — его название, адрес, услуги, цены и фото на общем шаблоне.

## Как устроено
- Один файл на салон: `salons/<slug>.json`, его фото — `salons/<slug>/…` (в ссылках: `/<slug>/cover.jpg`).
- `./deploy/deploy.sh` собирает всё (`out/`) и кладёт на сервер в `~/nails`. Caddy отдаёт `/<slug>`, если такая
  папка есть, остальное — приложению автосервисов (настройка — `shina-booking/deploy/Caddyfile`).
- Скрипт проверяет, что адрес не занят точкой автосервиса.
- Записи и правки в кабинете (`/<slug>/#/admin`) пока живут **в браузере** того, кто смотрит. Для демо этого
  достаточно; до боевого запуска нужен сервер (см. README → «Что нужно до боевого запуска»).

## Файл салона
Чего нет в файле — пусто (мастеров, работ, отзывов нет; демо-занятость выключена; демо-отзывы `demo: true` отбрасываются).
Вымышленное содержимое LUMI берётся только при `"base": "lumi-demo"` (так устроен `lumi.json`).
Сборка не пропустит салон без `studio.name`, `studio.address`, услуг или с ценой 0.

Оформление: `"theme": { "preset": "mulberry" | "taupe" | "rose" }`, по желанию `"accent": "#7F363F"` (тёмный).
Если у салона уже есть DIKIDI/YCLIENTS: `"booking": { "mode": "external", "url": "https://…", "name": "DIKIDI" }` —
кнопки ведут туда, своей сетки времени на сайте нет.

```json
{
  "slug": "nail-room",
  "studio": {
    "name": "Nail Room", "kind": "студия маникюра", "city": "Красноярск",
    "address": "ул. Ленина, 10", "addressNote": "", "map": [92.87, 56.01],
    "phone": "+7 (913) 000-00-00", "telegram": "", "whatsapp": "", "vk": "",
    "heroTitle": "", "heroPhoto": "/nail-room/cover.jpg", "timezone": "Asia/Krasnoyarsk"
  },
  "theme": { "preset": "taupe" },
  "masters": [{ "id": "m1", "name": "Мастер", "role": "Маникюр и педикюр", "about": "",
    "schedule": [{"open":"10:00","close":"20:00"}, …7 дней, null — выходной], "daysOff": [], "serviceIds": [] }],
  "services": [{ "id": "manicure-gel", "title": "Маникюр + покрытие", "note": "", "minutes": 105,
    "price": 2200, "priceFrom": true, "category": "hands", "photo": "/nail-room/1.jpg" }],
  "works": [],
  "reviews": []
}
```
Поля и их смысл — `src/data/types.ts`. Неделя в `schedule` начинается с понедельника.

## Правила
1. Только их услуги и цены (2ГИС, ВК, прайс), не выдумывать. Нескольких цен — минимальная с `priceFrom: true`.
   Услугу без цены не добавлять: «Цена у мастера» шаблон пока не умеет (0 покажется как «0 ₽»).
2. Рейтинг и отзывы — только настоящие (`reviews: []`, если нет).
3. Фото — только их работы. Нет — фото шаблона, в сообщении сказать «фото для примера».
4. Мастера — настоящие имена, если они есть в карточке; иначе один мастер «Мастер» (блок «Мастера» скрывается).
