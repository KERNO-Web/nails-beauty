# Передача работы — сайт nail-студии LUMI

Контекст из облачного чата для следующей (локальной) сессии. Код — в этом репозитории,
ветки `main` и `claude/adoring-tesla-tpd55z` совпадают. Демо: https://kerno-web.github.io/nails-beauty/ (кабинет — `#/admin`).

## Что это

Шаблон сайта онлайн-записи для nail-студии (React 19 + Vite + TS). Данные пока в браузере (localStorage,
`src/lib/store.ts`), движок свободного времени — `src/lib/slots.ts`. Подробно — README.md.

## Дизайн (с 16.10.2026 — третья версия)

По ТЗ `LUMI_ZERO_BASE_FULL_REINVENTION_PROMPT.md` всё оформление сделано заново: Prata + Manrope, палитры Бордо/Какао/Слива,
разделённый первый экран, меню-прайс, лента работ (README → «Дизайн»). Ветки: `lumi-3` — текущая, `lumi-2` — отклонённая
версия на Tenor, `wip/hero-material-lab` — исходная с WebGL-каплей.

Остаётся в силе: отзывы и цифры только настоящие, демо помечается; клик по мастеру — галерея его работ; фильтры
«Мастер» и «Стиль» раздельные; на месте мастера — настоящее фото или три его работы.

## Сделано последним

- Кабинет как приложение на телефоне (PWA) + гайд установки iPhone/Android + кнопка «Подключить уведомления».
- Напоминания клиенткам за 24, 12, 3 и 1 час: карточка на экране «вы записаны», гайд для клиентки,
  в приложении с рабочего стола — ввод телефона. «В календарь» (.ics) ставит 4 напоминания без сервера.
  Код: `src/lib/push.ts`, `src/notify/`.
- `server/` — сервер уведомлений (Node + web-push, JSON-файл, много студий: `/s/<студия>/…`, тесты `npm test`).
  Сайт шлёт на него записи и отмены, если задан `studio.push` или при сборке `VITE_VAPID_PUBLIC_KEY` + `VITE_PUSH_SERVER`.
